# The Dreamcart!

<img src="images/thing.png" alt="Dreamcart 64" width="320">

Not to be confused with the piece of furniture of the same name...

This is a cartridge reader for Dreamcast that supports N64, SNES, and Genesis (or Mega Drive if that's your fancy).
It can be used to play games on Dreamcast via an emulator or through a dynamic recompiler (the latter is being refactored and cleaned up before publishing here).
